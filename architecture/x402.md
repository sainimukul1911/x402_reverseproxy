# x402.rs - x402 Payment Protocol

Implements the Coinbase x402 protocol for HTTP micropayments.

---

## Overview

This module handles the entire x402 payment flow:
1. Generate `PAYMENT-REQUIRED` headers for 402 responses
2. Parse `PAYMENT-SIGNATURE` headers from clients
3. Verify payments with external facilitator
4. Settle payments after successful requests
5. Generate `PAYMENT-RESPONSE` headers for confirmation

---

## x402 Protocol Summary

```
Client                          Proxy                     Facilitator
   │                              │                            │
   │ ─── GET /api/resource ─────► │                            │
   │                              │ (rate limited)             │
   │ ◄── 402 + PAYMENT-REQUIRED ─ │                            │
   │                              │                            │
   │ (makes payment)              │                            │
   │                              │                            │
   │ ─── GET + PAYMENT-SIGNATURE ► │                            │
   │                              │ ── POST /verify ──────────►│
   │                              │ ◄── { isValid: true } ──── │
   │                              │                            │
   │                              │ ── Forward to upstream ──► │
   │                              │                            │
   │                              │ ── POST /settle ──────────►│
   │                              │ ◄── { success: true } ───  │
   │ ◄── 200 + PAYMENT-RESPONSE ─ │                            │
```

## HTTP Headers

| Header | Direction | Encoding | Content |
|--------|-----------|----------|---------|
| `PAYMENT-REQUIRED` | Server → Client | Base64 | `PaymentRequirements` JSON |
| `PAYMENT-SIGNATURE` | Client → Server | Base64 | `PaymentPayload` JSON |
| `PAYMENT-RESPONSE` | Server → Client | Base64 | `SettleResponse` JSON |

### `X402Handler::new(...)`

Creates handler with default payment requirements.

```rust
pub fn new(
    facilitator_url: String,
    recipient_address: String,
    amount: String,
    network: String,
    token: String,
    description: String,
) -> Self {
    let default_requirements = PaymentRequirements {
        scheme: "exact".to_string(),
        network,
        max_amount_required: amount,
        resource: "/".to_string(),  // Updated per-request
        description,
        mime_type: "application/json".to_string(),
        pay_to: recipient_address,
        max_timeout_seconds: 60,
        asset: token,
        extra: None,
    };
    
    Self {
        client: reqwest::Client::new(),
        facilitator_url,
        default_requirements,
    }
}
```

### `generate_payment_required_header(resource) -> String`

Creates Base64-encoded header for 402 response.

```rust
pub fn generate_payment_required_header(&self, resource: &str) -> String {
    let mut requirements = self.default_requirements.clone();
    requirements.resource = resource.to_string();
    
    let json = serde_json::to_string(&requirements).unwrap();
    BASE64.encode(json.as_bytes())
}
```

### `parse_payment_signature(header_value) -> Result<PaymentPayload>`

Decodes and parses client's payment header.

```rust
pub fn parse_payment_signature(&self, header_value: &str) -> Result<PaymentPayload, X402Error> {
    let decoded = BASE64.decode(header_value)?;
    let payload: PaymentPayload = serde_json::from_slice(&decoded)?;
    Ok(payload)
}
```

### `verify_payment(payment, resource) -> Result<bool>`

Calls facilitator to verify payment is valid.

```rust
pub async fn verify_payment(
    &self,
    payment: &PaymentPayload,
    resource: &str,
) -> Result<bool, X402Error> {
    let mut requirements = self.default_requirements.clone();
    requirements.resource = resource.to_string();
    
    let request = VerifyRequest {
        payment_payload: payment.clone(),
        payment_requirements: requirements,
    };
    
    let url = format!("{}/verify", self.facilitator_url);
    let response = self.client
        .post(&url)
        .json(&request)
        .send()
        .await?;
    
    let verify_response: VerifyResponse = response.json().await?;
    
    if verify_response.is_valid {
        Ok(true)
    } else {
        Err(X402Error::VerificationFailed(
            verify_response.invalid_reason.unwrap_or_default()
        ))
    }
}
```

## Error Handling

```rust
#[derive(Error, Debug)]
pub enum X402Error {
    #[error("Invalid payment signature header")]
    InvalidSignature,
    
    #[error("Failed to decode base64: {0}")]
    Base64Decode(#[from] base64::DecodeError),
    
    #[error("Failed to parse JSON: {0}")]
    JsonParse(#[from] serde_json::Error),
    
    #[error("Facilitator request failed: {0}")]
    FacilitatorRequest(#[from] reqwest::Error),
    
    #[error("Payment verification failed: {0}")]
    VerificationFailed(String),
    
    #[error("Payment settlement failed: {0}")]
    SettlementFailed(String),
}
```

## Integration with Proxy

In `proxy.rs`:

```rust
// On rate limit exceeded
let header = self.x402_handler.generate_payment_required_header(&ctx.path);
response.insert_header("PAYMENT-REQUIRED", header);

// On request with payment
if let Some(sig) = session.req_header().headers.get("PAYMENT-SIGNATURE") {
    let payment = self.x402_handler.parse_payment_signature(sig)?;
    if self.x402_handler.verify_payment(&payment, &ctx.path).await? {
        // Bypass rate limits, forward request
    }
}

// On successful response with payment
if ctx.paid {
    let settle = self.x402_handler.settle_payment(&payment, &ctx.path).await?;
    response.insert_header("PAYMENT-RESPONSE", ...);
}
```
